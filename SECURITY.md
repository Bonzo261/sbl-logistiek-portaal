# Beveiliging

## Een kwetsbaarheid melden
Meld beveiligingsproblemen **niet** in een openbaar issue. Gebruik op GitHub de knop *Security → Report a vulnerability* (privé melding) van deze repository. Beschrijf wat je gevonden hebt, hoe het te reproduceren is en welke versie je gebruikt. Stuur geen echte persoonsgegevens mee.

Ik probeer binnen enkele werkdagen te reageren en een oplossing te publiceren in een nieuwe versie; zie `CHANGELOG.md`.

## Ondersteunde versies
Alleen de nieuwste versie wordt bijgewerkt. Werk bij naar de nieuwste image.

## Meer informatie
Wat de app verwerkt en welke maatregelen er zijn, staat in [`docs/PRIVACY-EN-BEVEILIGING.md`](docs/PRIVACY-EN-BEVEILIGING.md). Wie de software draait is zelf verantwoordelijk voor de server, HTTPS, back-ups en het opruimen van gegevens.
